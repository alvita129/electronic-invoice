# Electronic Invoice
Electronic Invoice is a web-based application developed as an undergraduate thesis project. The system is designed to digitize the invoice management process, including invoice creation, approval workflow, and audit trail recording.

## Tech Stack
- Java 17
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- PostgreSQL
- Maven

## Features
- User Authentication
- Role-Based Authorization
- Electronic Invoice Management
- Approval Workflow
- Audit Trail
